## Proje ozellikleri
* **Sadece frontend:** Herhangi bir veri tabanı veya api yok sadece derste işlenen statik arayüz yapıldı
* **Sekme destegi yani bonus puan:** Bottomnavigationbar ve indexedstack kullanılarak sekmeler arası gecis saglandı
* **Görsel ozgünlük:** Tasarımda koyu gece mavisi ve sarı renk tonları seçilerek kurumsal portal teması yapıldı

## Kullanılan temel widgetlar
* **Yapısal yapılar:** Scaffold appbar drawer
* **Yerleşim duzenleri:** Column row listview card
* **Arayüz elemanları:** Text icon card circleavatar container padding divider
